# Backlog

**Purpose**: Tasks that sit outside every feature's phase order — defects and refinements found along the way that no story depends on, and work deferred because it waits on something outside the project, such as a device. Kept here, in one file, rather than at the end of whichever feature's `tasks.md` raised them, so they are not lost once that feature is done. Each is picked up when it is chosen, not when a phase comes round.

**Conventions**: Ids are the same series as every feature's tasks (`.claude/rules/workflow.md`) — a task raised here takes the next free id, after reading every `specs/*/tasks.md` and this file for the highest. Tasks are grouped by the feature that raised them, and a story label, FR, SC, or research id inside a task refers to that feature's documents. A task that needs a physical device the project does not have goes in the last section, Waiting for devices, whatever feature raised it, and stays there until the device arrives — grouped there by feature in the same way — so the list above it is work that can be picked up today. Closing one marks it `[X]` here in the same commit, with the id in the commit scope as for any task.
